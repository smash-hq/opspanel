Server Plane 使用文档

🚀 快速开始

打开面板后，从左侧节点列表选择一台服务器开始使用。

  • 本机节点：自动检测，无需配置
  • 远程节点：点击「＋ 添加节点」配置 SSH 连接

📊 系统概览

查看服务器的 CPU、内存、磁盘、运行时间等系统指标。

  • 点击 ↻ 刷新 获取最新数据
  • 数据通过 WebSocket 实时推送，每 3 秒自动更新

📦 软件管理

在「软件管理」Tab 中管理服务器上的软件。

  • 安装软件：点击「安装」按钮一键安装
  • 服务控制：启动 ⏸ 停止 ↻ 重启 ✗ 卸载
  • 查看日志：点击 📋 查看服务运行日志

📋 日志查看

支持查看 systemd 服务日志和 Docker 容器日志。

  • 可选择显示 50/100/200/500 行
  • 点击「↻ 刷新」获取最新日志

⚙️ 系统设置

点击左下角齿轮图标进入设置。

  • 外观主题：白天 / 夜间 / 跟随系统
  • 网站图标：自定义浏览器标签页图标
  • 软件源：管理镜像源和仓库地址

🔗 连接测试

添加远程节点时，可先点击「⚡ 测试连接」验证 SSH 凭据。

  • 支持密码认证和私钥认证
  • 连接成功后会显示远程主机基本信息
