Server Plane 使用文档

🚀 快速开始

打开面板后，从左侧节点列表选择一台服务器开始使用。

  • 本机节点：自动检测，无需配置
  • 远程节点：点击「＋ 添加节点」配置 SSH 连接

📊 系统概览

查看服务器的 CPU、内存、磁盘、运行时间等系统指标。

  • 点击 ↻ 刷新 获取最新数据
  • 数据通过 WebSocket 实时推送，每 3 秒自动更新

📦 软件管理

在「软件管理」Tab 中管理服务器上的软件。

  • 安装软件：点击「安装」按钮一键安装
  • 服务控制：启动 ⏸ 停止 ↻ 重启 ✗ 卸载
  • 查看日志：点击 📋 查看服务运行日志

📋 日志查看

支持查看 systemd 服务日志和 Docker 容器日志。

  • 可选择显示 50/100/200/500 行
  • 点击「↻ 刷新」获取最新日志

⚙️ 系统设置

点击左下角齿轮图标进入设置。

  • 外观主题：白天 / 夜间 / 跟随系统
  • 网站图标：自定义浏览器标签页图标
  • 软件源：管理镜像源和仓库地址

🔗 连接测试

添加远程节点时，可先点击「⚡ 测试连接」验证 SSH 凭据。

  • 支持密码认证和私钥认证
  • 连接成功后会显示远程主机基本信息

PERMISSION

权限说明

服务以部署时指定的运行用户身份执行操作，无需 root 也能查看大部分信息。如遇权限不足，可参考以下方式提升权限。

本机节点

本机节点由服务进程直接读取 /proc、/sys 采集系统信息，通常无需任何额外权限。以下操作可能受限：

  • 结束其他用户的进程
  • 浏览受保护的文件/目录（如 /etc/shadow、其他用户主目录）
  • 管理 Docker 容器（运行用户不在 docker 组时）

方式一：配置免密 sudo（推荐）——服务执行失败时会自动尝试 sudo -n 免密提权：

sudo visudo -f /etc/sudoers.d/server-plane
# 写入以下内容（smpuser 替换为服务运行用户）：
smpuser ALL=(ALL) NOPASSWD: ALL
# 保存后设置安全权限：
sudo chmod 0440 /etc/sudoers.d/server-plane

方式二：以 root 运行服务——修改 systemd unit 中 User=root 后 systemctl daemon-reload && systemctl restart。简单直接，但权限过大，不建议在生产环境使用。

Docker 管理：将运行用户加入 docker 组（重新登录后生效）：

sudo usermod -aG docker smpuser

远程节点

远程节点通过 SSH 用户执行命令，非 root 用户同样存在上述限制。建议为 SSH 用户配置 NOPASSWD 免密 sudo，详细步骤参见项目文档 docs/sudo-setup.md。
